## Remaining boundaries

This is a source-preservation pass, not a proof that every project conversation or literary manuscript has been recovered. Unknown current resources remain unknown. The source text is complete as returned, but DOCX formatting and images are not reconstructed. Print trackers retain their original PDFs.

Known source conflicts are preserved: Barten older Crew Ledger build versus Earth Gnome progression sheet; Matthael level 6/8/10 snapshots; source house-rule ambiguity; Ti companion-sidekick module versus older familiar shorthand. No build or resource state is silently combined.
